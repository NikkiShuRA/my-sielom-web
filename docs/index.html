Отправная точка

Официальное расписание показывает данные. И только.

  • ✕Не знает, который час. Чтобы понять, какая пара идёт и сколько до конца, — смотри на часы и считай сам.
  • ✕Пустота на телефоне. Три карточки «Нет пары» занимают весь экран, а первая настоящая пара — где-то внизу.
  • ✕Только светлая тема. Вечером в 18:00 по пути с пар — прямо в глаза.
  • ✕Нет поиска по тексту и подробностей. Группа выбирается через корпус и курс, клик по паре ничего не открывает.

Главная фича

Сразу видно, что сейчас

Расписание пересчитывается каждую минуту. Текущая пара подсвечена, внизу полоса прогресса, следующая помечена «через N мин», прошедшие схлопываются в строку.

  • 1Таймер «Идёт · ещё 38 мин» прямо на карточке
  • 2Пересменка и перемены между парами видны на таймлайне
  • 3Попробуйте сами — двигайте ползунок времени справа

Два режима · три темы

Вся неделя одним взглядом

«Неделя» — шесть колонок, сегодняшний день выделен жёлтым, прошедшие пары приглушены. «День» — таймлайн с подробностями. Режим запоминается.

  • ◐Системная, светлая или тёмная тема — применяется до отрисовки, без белой вспышки
  • ⇆Перетаскивание мышью по сетке недели и свайпы по дням на телефоне
Три расписания в одном месте

Группы. Преподаватели. Кабинеты.

Один тап — всё о паре

Где, кто, с кем

  • 📍Аудитория, номер корпуса и адрес — не нужно вспоминать, где «Пролетарский, 3»
  • 👤Полное ФИО преподавателя с аватаром из базы сотрудников
  • ↗Переходы по ссылкам: клик по преподавателю открывает его расписание, по группе — расписание группы
  • ½Подгруппы — когда группа делится, обе половины видны с кабинетами и преподавателями
  • !Примечания о переносах и заменах — со значком предупреждения
Сделано для телефона

Расписание — в кармане, а не в зуме

На телефоне открывается режим «День»: полоса дней недели сверху, свайп влево-вправо листает дни, подробности выезжают нижней шторкой. Все кнопки — от 44 px под палец.
