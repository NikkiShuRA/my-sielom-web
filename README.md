# Расписание СИЭУиП

Неофициальный клиент расписания Санкт-Петербургского института экономики, управления и права. Быстрый, удобный и красивый — всё то, чего нет в официальной версии.

**→ [sielom.vercel.app](https://sielom.vercel.app)**

---

## Зачем это нужно

Официальное расписание на сайте колледжа — таблица из нулевых: мелкий шрифт, никакой адаптации под телефон, нет тёмной темы, невозможно быстро понять «что сейчас идёт и сколько осталось». Этот проект переосмысляет опыт просмотра расписания с нуля.

| | Официальное | Этот проект |
|---|---|---|
| Мобильная версия | Таблица, нужно зумировать | Полноценный адаптив |
| Тёмная тема | Нет | Есть, следует системной |
| Текущая пара | Нужно смотреть на часы | Подсвечена + таймер |
| Избранное | Нет | Сохраняются группы, преподаватели, кабинеты |
| Расписание преподавателей | Отдельная страница | Встроено |
| Расписание кабинетов | Нет | Есть |
| Фото преподавателей | Нет | Есть (аватарки) |
| Навигация с клавиатуры | Нет | Полная |

## Возможности

### Три типа расписаний
- **Группы** — с фильтрацией по корпусу и курсу
- **Преподаватели** — поиск по имени, фото из базы колледжа
- **Кабинеты** — просмотр занятости любого кабинета

### Два режима просмотра

**День** — лента пар с таймлайном:
- Текущая пара выделена жёлтым с живым таймером («Идёт · ещё 34 мин»)
- Полоса прогресса показывает сколько пары прошло
- Следующая пара помечена чипом «Следующая» / «Через N мин»
- Прошедшие пары сворачиваются в компактную строку
- Перемены отображаются между парами

**Неделя** — 6 колонок, вся неделя сразу:
- Компактный вид для быстрого обзора
- Сегодняшний день подсвечен
- Прошедшие пары приглушены

### Карточка пары
- Название предмета, время, номер пары
- Кабинет + преподаватель (для групп) или группа + преподаватель (для кабинетов)
- Поддержка подгрупп: корректно отображает, когда группа делится
- Примечания к паре (изменения, переносы) со значком предупреждения
- Клик → подробная информация в модальном окне

### Модальное окно пары
- Полное место проведения: кабинет, корпус, адрес
- Преподаватель с фото
- Для расписания преподавателя: список групп/подгрупп, каждая кликабельна → переход в расписание группы
- Для расписания кабинета: информация о занятии

### Избранное
- Добавление в один клик (иконка закладки)
- Три раздела: Преподаватели / Группы / Кабинеты
- Мгновенный доступ через кнопку ★ в шапке
- Сохраняется между сессиями

### Поиск
- Мгновенный поиск по списку (без перезагрузки)
- Навигация по корпусам и курсам для групп
- Клавиша `/` — фокус на поиск

### Горячие клавиши

| Клавиша | Действие |
|---|---|
| `←` / `→` | Предыдущий / следующий период |
| `T` | Вернуться к сегодня |
| `/` | Открыть поиск |
| `D` | Переключить тему оформления |
| `Esc` | Закрыть модальное окно / очистить поиск |

### Тёмная тема
- Три режима: Системная / Светлая / Тёмная
- Применяется мгновенно, без вспышки при загрузке
- Сохраняется в localStorage

### Адаптивный дизайн
- Телефон: шторка с поиском снизу, тач-цели ≥ 44 px
- Планшет и десктоп: боковая панель с поиском
- Корректно работает на любом размере экрана

## Стек

```
HTML + CSS + Vanilla JS    — никаких фреймворков, SPA на одном файле
Vercel                     — хостинг + serverless proxy
Vercel Functions           — обход CORS к API sielom.ru и strapi.sielom.ru
Wix Madefor Display        — шрифт
```

Данные берутся из официального API колледжа через прокси-функцию, поэтому расписание всегда актуальное.

## Запуск локально

```bash
git clone https://github.com/NikkiShuRA/my-sielom-web.git
cd my-sielom-web
```

Нужен локальный сервер (например [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) в VS Code) и проксирование запросов к API — или установи [Vercel CLI](https://vercel.com/docs/cli):

```bash
npm i -g vercel
vercel dev
```

Откроется на `http://localhost:3000`.
